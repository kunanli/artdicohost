## ABOUT 活动介绍
第十九届 Global Game Jam 计划于 2027 年 1 月 25–31 日举行。为促进各地站点之间的经验分享与交流，我们计划于 2026 年 12 月 5 日在深圳前海举办 GGJ 中国交流聚会，并与 ARTDiCO HOST 学生嘉年华同期举行。活动将连接 GGJ 组织者、游戏开发者、高校及产业生态伙伴，共同探讨站点运营、创作与行业合作的可能性。

## HIGHLIGHTS 活动亮点
GGJ 主题分享：交流 Global Game Jam 相关资讯与经验（嘉宾及主题待确认）。
组织者圆桌会议：围绕站点经验、组织难题和跨城合作深入交流。
新站点申请咨询：面向有意建立 GGJ 站点的组织者，提供申请咨询与初步审核；最终资格以 GGJ 正式流程为准。
产业技术与专题交流：邀请游戏产业、高校与工具生态嘉宾分享。
ARTDiCO HOST 作品展示：青年创作者介绍游戏及数字艺术作品，获得现场交流与反馈。
展位体验与生态合作：约 15 个展位，展示游戏、技术、社区项目与合作资源。
