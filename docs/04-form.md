# 意向登记表单 — 问题、分支及验证

## 基础题
1 姓名（必填，2–80 字）
2 城市（必填）
3 所属机构（必填；独立个人可填「独立开发者」）
4 职位/身份（必填）
5 邮箱（必填，格式验证）
6 微信号（建议填写；如果不填需提供替代联络方式）
7 个人/机构网站（选填，验证 http/https）
8 目前的参与身份（多选）：GGJ SO / GGJ RO / 有意建立新站点 / 游戏行业嘉宾或开发者 / 高校教育机构 / 生态合作伙伴 / 其他
9 希望的参与方式（多选）：站点圆桌 / 主题演讲 / 专题研讨 / 展位展示 / 站点支持 / 生态合作或资源赞助 / 学员作品交流 / 仅出席
10 相关经历或机构简介（必填，建议 30–1000 字）
11 相关站点/案例/作品链接（选填）
12 12 月 5 日出席意向（预计可到场 / 尚待确定 / 暂无法出席）
13 是否申请**一晚**住宿支持（需要 / 不需要 / 尚不确定）
14 若申请，请填出发城市；入住及离店时间为暂定 12 月 5–6 日，不在第一阶段要求证件。
15 希望交流的议题、可提供的资源或合作机会（选填）
16 所属机构是否有兴趣与 GGJ 探索未来合作机会（有兴趣 / 希望了解更多 / 暂无计划）
17 潜在合作形式（多选且选填）：活动联合推广 / 技术与工具资源 / 资金或物资支持 / 专业导师 / 社群交流 / 教育合作 / 其他
18 个人信息处理告知及同意（必须主动勾选，不预选，拒绝则不提交）。

## 条件分支
SO/RO：站点名称、城市、首次组织年份、当前/历史角色、是否愿意交流案例；服务年资及表彰必须另表核验，不得自动评奖。
新站点：申请城市、所属机构、场地是否具备、团队是否就绪、计划参加 2027 GGJ、希望获得的支持。
演讲意向：拟分享主题、摘要、分享语言、相关案例；详细讲者照片与素材获邀后再收。
展位意向：展示项目类型、简介、链接、参展人数估计、初步设备需求；获批后再收完整布展材料。
合作伙伴：合作方向、可提供的资源、机构背景，资金或物资支持为可选，不暗示承诺赞助。

## 行为
用户选择多个身份时可显示多个分支，最终只存一条申请。若分支不再适用，不传送已隐藏的过时值。私有信息不得放 localStorage 长期保存。提交需服务器限流、校验、去重；出错不能回成功。住宿审批与出席审批必须分开。
