# 后台管理与 Maria 确认工作流

## 后台路径
`/admin/`；登录沿用参考仓库安全模式但使用 ARTDiCO 独立账号、私有桶和新会话密钥。禁止 IGDA 账号自动继承权限。登录输入用户名或明确配置的 `@artdico.co` 邮箱，配合同一账号密码；域名不自动创建账号或授予权限。实际账号资料、密码摘要和会话只在受控后端保存，不放静态网页或 Git。本机模块已支持两种识别，云端后台仍待独立鉴权与存储适配，不能将启动健康检查视为可登录。

## 名单概览
搜索：姓名、机构、城市、类型、申请时间。
筛选：SO/RO/新站点/产业嘉宾/教育/生态伙伴、参与方式、住宿申请、到场意向、审核状态。
单条详情：申请人填写的原始资料 + ARTDiCO 内部标注（不可由公众更改）。

## 两套状态（不可混用）
候选审核：new / in_review / awaiting_maria / approved / discussion / not_this_time / withdrawn
住宿审核：not_requested / requested / pending / approved / declined
内部推荐：priority / consider / follow_up（仅供工作参考，不等同于 Maria 审核）

## 资料审核字段
推荐参与方式、站点历史核验备注、活动讲者或展位候选、内部负责人、上次联系日期、下一步、Maria 审核日期和反馈、最终邀请状态。任何变更记录操作者及时间，不把完整个人资料写入日志。

## 审核权限
superadmin：用户管理、全部申请、导出、删除处理。
reviewer：查看已授权事件报名、分类、备注、有限导出（如获许可）。
editor：仅编辑公开活动内容；默认不能读取报名信息。
Maria：默认由指定管理员导出最小必要字段并通过受控渠道发送，不自动生成公开链接；若未来有直接登录须另设计角色和权限。

## 导出 Excel/CSV
必要字段：姓名、机构、城市、联系窗口（如确有必要）、申请类别、背景摘要、申请角色、意向、ARTDiCO 推荐、Maria 意见、跟进状态。导出操作需审核权限与审计记录。避免 CSV 公式注入，限制敏感字段。不得将原始完整数据库直接对外转发。

## 容量管理
现场席位、约 15 展位、住宿预算约 20 间房属于不同配额。住宿原则一人一晚；不得按申请顺序自动批准，需人工确认客房数量与相应入住晚数。每晚容量独立核算。
