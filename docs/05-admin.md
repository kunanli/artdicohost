# 后台管理

2026-11-26 更新。正式后台入口为 `https://api.artdico.host/admin/`。用已配置的 ARTDiCO 工作人员用户名或账号邮箱登录。账号与权限独立管理，IGDA 账号没有自动授权。[打开后台](https://api.artdico.host/admin/)

## 当前工作入口

| 工作 | 入口与操作 |
| --- | --- |
| 报名、名额、取消和签到 | 参与者从活动行取得原电子票，现场工作人员在活动行核验。旧网站签到和旧私人入场短链接只显示活动行指引。[活动行活动页](https://9525102647817.huodongxing.com/event/8884819113200) |
| 人员与活动行 | 选择「导入活动行」，上传本次活动的原始 `.xlsx`，核对有效票、同一人关联与授权，再按选择导入。导入是内部名册核对，活动行票券、名额及后续退票以活动行为准。回执不明时用「核对原导入」处理原操作。 [人员与活动行](https://api.artdico.host/admin/contacts/) |
| 电子纪念卡 | 核对活动行原票，通过纪念卡申请。保存身份和选填资料，预览当前卡面后再明确寄送。回执不明先核对寄送结果。多次测试使用自己的邮箱及「新增测试卡」。移除会撤销线上领取资格。 [纪念卡](https://api.artdico.host/admin/cards/) |
| 志愿者与分工 | 人员按已核实的合并身份排班。已归档联系人退出待办及选单，仍可沿用其有效独立报名。已排期场次和已确认展位计入有效安排，草稿保留供规划。保存或 Excel 导出回执不明时先核对原操作，导出在原标签页处理。 [志愿者与分工](https://api.artdico.host/admin/volunteers/) |
| 活动与内容 | 按权限维护基本资料、嘉宾、场次、展位和作品。保存草稿后再核对全部待发布项目，并明确发布。 [活动与内容](https://api.artdico.host/admin/) |
| 历史资料与设置 | 已保存的旧报名、邀约及通知回执按原权限查阅。旧网站报名、代登记、名额操作、正式参会确认信和行前提醒已停用，讲者申请已关闭。电子纪念卡寄送仍在纪念卡页面进行。 [历史报名记录](https://api.artdico.host/admin/registrations/) · [后台设置](https://api.artdico.host/admin/settings/) |

审核人或管理员可核对纪念卡领取资格及卡面资料。寄送、重寄、新增测试卡和移除需超级管理员权限，或同时具备编辑、发布、邀约和审核四项权限。 [完整操作手册](redesign/02-staff-and-attendee-runbook.md)

## 早期 Maria 审核方案（历史）

以下保留项目早期的内部审核、导出和住宿设计。里面的名单状态、权限交接和配额示例用于查阅旧资料，当前正式报名、撤回和签到以活动行为准。

### 后台路径与原设计

`/admin/`；登录沿用参考仓库安全模式但使用 ARTDiCO 独立账号、私有桶和新会话密钥。禁止 IGDA 账号自动继承权限。登录输入用户名或明确配置的 `@artdico.co` 邮箱，配合同一账号密码；域名不自动创建账号或授予权限。实际账号资料、密码摘要和会话只在受控后端保存，不放静态网页或 Git。本机模块已支持两种识别，云端后台仍待独立鉴权与存储适配，不能将启动健康检查视为可登录。

### 名单概览

搜索：姓名、机构、城市、类型、申请时间。
筛选：SO/RO/新站点/产业嘉宾/教育/生态伙伴、参与方式、住宿申请、到场意向、审核状态。
单条详情：申请人填写的原始资料 + ARTDiCO 内部标注（不可由公众更改）。

### 两套状态（不可混用）

候选审核：new / in_review / awaiting_maria / approved / discussion / not_this_time / withdrawn
住宿审核：not_requested / requested / pending / approved / declined
内部推荐：priority / consider / follow_up（仅供工作参考，不等同于 Maria 审核）

### 资料审核字段

推荐参与方式、站点历史核验备注、活动讲者或展位候选、内部负责人、上次联系日期、下一步、Maria 审核日期和反馈、最终邀请状态。任何变更记录操作者及时间，不把完整个人资料写入日志。

### 审核权限

superadmin：用户管理、全部申请、导出、删除处理。
reviewer：查看已授权事件报名、分类、备注、有限导出（如获许可）。
editor：仅编辑公开活动内容；默认不能读取报名信息。
Maria：默认由指定管理员导出最小必要字段并通过受控渠道发送，不自动生成公开链接；若未来有直接登录须另设计角色和权限。

### 导出 Excel/CSV

必要字段：姓名、机构、城市、联系窗口（如确有必要）、申请类别、背景摘要、申请角色、意向、ARTDiCO 推荐、Maria 意见、跟进状态。导出操作需审核权限与审计记录。避免 CSV 公式注入，限制敏感字段。不得将原始完整数据库直接对外转发。

### 容量管理

现场席位、约 15 展位、住宿预算约 20 间房属于不同配额。住宿原则一人一晚；不得按申请顺序自动批准，需人工确认客房数量与相应入住晚数。每晚容量独立核算。
