# 參會體驗前端與精簡 VI

2026-10-21，本階段候選功能，最終正式發布證據見[接續台帳](session-recovery.md)。本檔記錄界面契約與驗收方式，不表示真實名單已遷移、郵件已送達或 Apple 票券已可使用。

## 人物、組織與私密安排

活動後台維護公開人物的姓名、職稱、機構、公開職責、簡介、網站及照片；已確認且有獨立公開授權的人物才進入前台。卡片先顯示姓名／職責／機構，展開後讀簡介、網站與真實已排場次，場次連結切換至對應日程區域。私人全活動或逐場職責只提供草稿建議，不自動建立公開講者，也不影響名額或住宿。

照片先在瀏覽器校正方向、縮小及重新編碼，原大圖不直接上傳；界面顯示預覽、尺寸與體積。處理失敗或取消保留明確狀態，不顯示完成。更改公開欄位或照片須重新核對授權；停止公開保留記錄和關聯，保存並發布後才改前台。完整限制與舊快照兼容見[人物與媒體](profile-media.md)。

組織卡片復用已確認攤位的組織／項目／公開內容／網站，不另造組織身分或贊助權益。攤位負責人、聯絡方式、原始回答與內部安排留在私密後台。[人員逐場職責](participant-duties.md)與[直接編排](direct-arrangements.md)分別維護，角色改動不刪除原件。

## 確認頁

公開表單收到已持久化、通過核對的報名收據，且含有效確認資訊時，跳轉 `https://artdico.host/registration/confirmation/#r=<receiptToken>`。沒有有效確認資訊時仍保留原成功收據，不撤銷已保存報名或要求重填。網址不含姓名、郵箱或 query 個資；私人 fragment 只由頁面送到固定確認／票券 API 的 POST 正文，不攜帶工作人員 Cookie，也不放入本機儲存。持有人能讀取該人的最小確認資料，複製後應私下保管。

| 目前名額狀態 | 確認頁行為 |
| --- | --- |
| confirmed | 顯示名額已確認、本人姓名／機構、活動／編號、郵件處理狀態；只有有效群碼才顯示，Wallet 另須完整簽章設定。 |
| waitlisted | 明示候補已保存、尚無確認名額，不顯示群碼或 Wallet；不因可列印而變成獲邀。 |
| withdrawn | 顯示取消，不顯示姓名／機構、群碼或 Wallet，保留核對編號與目前狀態。 |
| 無效／過期／服務無法核對 | 清除前次個資、QR 與票券下載，不顯示舊成功畫面；提示保留原編號並稍後核對，不重填。 |

重新讀取只讀目前狀態，不發送確認信。同一頁換到另一份 fragment 連結時，立即清除舊資料並隔離先前晚到回覆；頁面離開／返回也重新核對，避免把前一人的資料留在新連結下。頁面不自動輪詢，已開啟畫面及紙張只反映讀取當時狀態。

列印為 A4 白底，保留活動、姓名（資格有效時）、編號、處理狀態及當時狀態提示，隱藏導覽、操作按鈕、私人連結、複製備用欄位及群碼。列印前暫時移除網址 fragment，之後恢復，避免瀏覽器列印頁首／頁尾帶出 capability。列印件不是獨立入場或其他職責／住宿確認。

確認信只在已保存的公開報名後由服務端處理，讀頁與列印不觸發。未提供郵箱、未設定、停用、待處理、服務商接受、明確拒絕及結果未知均使用不同文字，接受不等於送達。取消或補位仍以當前名額為準。[服務／通知契約](registration-confirmation.md)。

## 設定與 Wallet

報名後台的「報名確認與票券」只供 superadmin 設定；API 同時校驗會話、角色、Origin、CSRF 及修訂。設定畫面只顯示 readiness、缺少的固定名稱及通知計數，敏感值透過[受控加密設定](delivery-configuration.md)處理，不填入網頁或聊天。啟用寄件服務前按確認信指引核對必要通知處理：僅傳收件郵箱、稱呼、活動事實、編號與私人確認連結，服務或模板不能公開該連結。明確補發逐人選擇公開報名，未知結果保留原操作重試入口；登出或權限改變清空資料，舊回覆不能恢復私人面板。

目前主辦方沒有 Apple Developer 帳號／簽章憑證；先交付[設定指引](apple-wallet-setup.md)與真實未就緒狀態。未就緒不顯示下載按鈕，不影響確認頁與列印。日後 confirmed 且簽章就緒時下載真實 `.pkpass`，頁面只表示文件已準備，不能宣稱已加入裝置。需 iPhone／Safari 實際驗證；微信內可改用 Safari。票券有效性 QR 讀取當前資格，不記錄簽到；已儲存票券不具推送更新或遠端刪除能力。

## 少即是多的 VI

保留現有字體、主色、活動識別與閱讀順序，刪除 Hero 四角裝飾文字、區段重複英文 kicker 及頁尾重複活動名稱／邀請預覽入口。人物與組織區保留一個中文主標、有用內文及必要職責標籤；時間、地點、狀態、表單提示與無障礙名稱仍清楚可讀。確認頁使用獨立白底卡片，手機可單欄操作，列印無裝飾背景。

驗收 390px 手機與桌面：頁面不橫向溢出；姓名、機構、長編號與網站可換行；鍵盤焦點可見；簡介展開和日程跳轉可操作；reduced motion 使用者不需動畫才能讀取內容。

| 腳本 | 重點 |
