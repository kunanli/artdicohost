## 为什么现在不能在正式网站登录

- [公开站点准备脚本](../scripts/prepare-oss-site.mjs)用“云端工作人员后台尚未开放”提示替换两个管理页面，未发布登录脚本或私有图片。
- FC 已部署[独立内容包](../scripts/prepare-cloud-content.mjs)，但内容开关保持 false；账号配置的新运行及真实私有 OSS／登录尚未验收，不能仅因后台页面或进程可达便宣称可用。
- 本机 API 仅绑定 `127.0.0.1` 并拒绝生产模式；本机会话和限流仅在单一进程内有效。不能直接把它上传 FC、代理上公网或把浏览器接到签名验收入口。
- 工作人员账号由独立受控配置 job 消费密码 Secret 与身份 Variables，尚待新运行成功；部署 Secret 本身不会建立账号或邮箱。三次签名健康检查只证明相应源码的进程启动通过。

邮箱作为登录标识与寄件邮箱是两项配置；填写 `@artdico.co` 不证明邮箱所有权、寄件域名核验或投递成功。账号密码与摘要只在受控服务端配置，不能写入公开页面或仓库，也无需在聊天提供。
