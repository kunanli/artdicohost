## 待执行的前端验收

1. 桌面与窄屏：所有锚点可到达；无页面横向溢出；日程切换保留时间和区域信息；15:30–17:00 学员展示安排可读。
2. 键盘与无障碍：跳过导航可用；焦点清楚；表单标签、必填及错误提示可关联；关闭动画偏好得到尊重；图标和颜色不是唯一提示。
3. 内容：普通参会采用活动直接报名，不设置意向审核或邀请门槛；讲座及讲者待确认，显示讲者及赞助商招募；演讲、赞助、展位、住宿分别处理。日期、Maria 出席、嘉宾、署名及地图保留适当待确认状态，不出现未经证实的权益或住宿承诺。
4. 表单：多身份分支可同时展开；取消选择后清理不适用值；拒绝隐私同意不能继续；非法邮箱、链接、枚举及住宿条件得到提示；只用合成资料。
5. 演示边界：提交路径明确告知未发送真实报名，不出现正式成功、正式查询编号或“已写入 OSS”；浏览器网络和持久存储不留填写资料。
6. 产物安全：检查公开构建不含秘密、真实报名资料或内部容量；没有生产接口回退地址或前端云凭据。

执行后用实际命令结果更新上表，并为浏览器验证补记 URL、页面类型、视口、日期和限制。检查失败保留失败事实及修复结果；云端与微信尚未验证的项目继续明确标记。
