新增 [本地内容后台](local-content-backend.md) 后，本机 Node 内置测试共执行 34 项：33 通过、0 失败、1 跳过；源码语法与报名无传输检查通过（61 文件）。其中内容 API 11 项为 10 通过、1 跳过，实际验证了合成账号、scrypt 配置、HttpOnly / SameSite cookie、Origin / CSRF、角色授权、单进程并发修订冲突、项目内隔离文件的原子替换、重启持久化、公开内容剥离和损坏文件拒绝重置。
