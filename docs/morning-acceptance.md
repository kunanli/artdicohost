# ARTDiCO HOST 验收与接续

本轮操作以[默认公开](default-public-visibility.md)、[统一保存](admin-save-workflow.md)和[设置回执](settings-save-feedback.md)为准，准确来源、检查与实际部署状态见[本轮验收／发布记录](admin-save-visibility-release-2026-10-22.md)及[接续台账](session-recovery.md)。PR42／43的[发布证据](games-publication-release-2026-10-21.md)是前一版本历史，其公开门槛、红绿公开状态和旧保存步骤不作为本轮操作指引。

内容九个子页及设置四个子页各自独立。修改后在实际表单附近按「保存」，核对本次云端回执才显示「已保存」；保存成功保留编辑对象。嘉宾、组织、游戏与作品、展位默认公开，列表开关直接保存，编辑窗开关随本表单保存；再按就近「发布到前台」或进入发布页明确发布，未保存填写先「保存并发布」。公开开关不确认出席、名额或授权，发布更新全部已保存活动内容。未知回执先核对原请求，不能换键盲建。

## 先验收这些流程

| 入口 | 操作与预期 |
| --- | --- |
| 活动与内容 | 修改当前表单，核对「未保存 → 保存中… → 已保存」及原位回执，继续修改并保存仍为同一对象；另一表单未提交输入保留。只读概况用编辑链接，不添加无效保存。已上传图片引用可恢复，原图文件须重新选择；保存不自动发布。 |
| 人员与邀约 | 原始资料保留，分别调整回复、负责人、跟进日期和职责；负责人使用固定彩色姓名标签、未分配灰色，回复attending绿、pending红未确认、declined红不出席；确认参加后核对共同名额。旧已答应者先预览再明确同步，不按姓名／邮箱另造人。个人工作页串联报名、嘉宾、组织、场次、展位和志愿分工。 |
| 嘉宾与组织 | 按稳定 ID 关联既有人物，组织选择明确成员。默认绿色「公开」，明确切成「未公开」并取得保存回执，再发布才撤下前台旧版；开关保留原出席、资料确认及授权事实。相关资料／照片变更仍清除当前表单的旧授权勾选供重核，不关闭公开开关。头像／公开职责选填，缺头像显示姓名首字；确认、照片及授权不再作为公开门槛。一般参加组织不自动占展位。 |
| 游戏与作品 | 学生／独立／团队统一维护，明确关联创作者组织及展位，同展位可多作品；旧学生ID／字段缺省及历史保留，分类和组织筛选可用，不把作品数／填报成员数当实际参会人数。 |
| 公开状态 | 绿色「公开」是设置，中性标签「待发布／已发布／待更新／待撤下」说明实际发布进度。切换设置不会重生成旧快照；按「发布到前台」明确更新，再返回前台核对。读取失败保留最后已核对内容，结果未知不能当作已发布。 |
| 公开申请 | 学生在身份选择；姓名、邮箱、身份和隐私同意为主要必填，机构／城市／微信选填，主题提案独立展开。提交是待审核，不是获邀；后台核准后有位确认并走确认信，满额候补。 |
| 300 人名额 | 所有参会与工作人员共用 300，不因多个角色或团队关系重复计数。候补、拒绝、撤回及待审核不算已确认；分配与审核分别保存。 |
| 志愿者与分工 | 选择既有人，填沟通与服务时间，建立岗位／班次后安排；人数与人次分列，冲突由后端拒绝，取消保留历史。 |
| 暂存与未知回执 | 常规本机暂存不显示主要成功提示，已载入云端草稿固定浮窗移除；只有恢复、冲突或未知提交时显示工具。中断／刷新后明确恢复，不自动云端提交／发布／寄信。结果未知只核对原请求，不能换键盲建；云端版本不同只查看旧填写。 |
| 邀请函 | 人员与邀约打开邀请函，按「使用本次活动信息准备新版」，核对姓名、日期、时段及地点后预览／保存／下载；旧派发历史保留。已核准且有名额的公开申请人在私人确认页按「生成个人邀请函 PNG」，核对完成后可下载或手机长按。生成图片不会发信或标记已派发。 |
| 用户管理 | 现有管理员登录[用户管理](https://api.artdico.host/admin/settings/accounts/)，先核对账号是否已存在；若未建立，分别按「准备 zhouyufei」「准备 wangying」自动生成独立初始密码；按「保存」，取得有效回执后从本页已确认的登录资料私下交付。成功后保留账号并清空密码，「新增账号」才开始下一笔。**本开发未代建两个正式账号，需核对后台现况**，密码不进缓存／Git／链接，离页后清除。 |
| 权限 | 两个协作者使用 editor／publisher／outreach／reviewer 完整组合，可日常编辑、发布、人员安排、审核、Excel 与通知。只有管理员可管理账号及系统备份／恢复；停用立即撤销旧会话。 |
| Excel | 人员及报名各自导出当前保存资料；联络、完整原回答、安排另选。Excel 用实际软件打开核对中文、前导零和状态；导出不代替完整备份。 |

本机暂存有短暂写入时间，不能用它判断云端保存成功；尚未完成离页会提醒。突然终止进程不能保证最后一个字落盘。普通草稿七天有效，未知提交不会因此失去原键。明确退出清除本账号本机草稿，跨页签同步；退出请求失败会说明云端会话尚未确认结束。
