## 交付与操作

入口是[活动后台](https://api.artdico.host/admin/)的「参与组织」。组织不需要先占展位，图片、名称、对方页面与参展／一般参与各自维护。原有四个已公开名称保留；没有替任何真实组织猜测图片、网址或参展形式，也没有把名录变更当作个人报名或占用 300 人名额。

1. 新增或编辑组织，填写名称，上传图片／Logo及有效 HTTP／HTTPS 页面链接；图片和链接可选。图片自动校正方向、缩至最长 800px并压到 512 KiB 内，保持原比例、移除元数据，透明处转为白底。
2. 独立选择「参展／一般参与／待确定」及「待确认／已确认／已退出」，核对公开授权，再应用、保存草稿及发布。一般参与不必新增展位，十五个展位仍在原模块安排。
3. 网站「参与组织」显示完整比例图片及名称，有有效链接时可点击图片／名称跳转；没有图片时保留名称，没有链接时不生成空链接。按后台顺序呈现。
4. 「停止公开」只撤销公开授权，保留参加确认状态、名称、图片、链接及内部备注；保存并发布才改变网站。全部撤回、显式空名单或 API 失败时不恢复旧组织。

完整字段、旧客户端兼容、图片授权及[备份／回退说明](participating-organizations.md)。本轮没有操作真实组织资料、上传真实 Logo、匯入 39 人、寄信或更改 Apple 设置。
