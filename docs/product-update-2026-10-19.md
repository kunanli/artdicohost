## 已确定的产品方向

1. 同级呈现「2026 GGJ 中国交流聚会」与「ARTDiCO HOST 学生嘉年华」双活动身份。延续白底、蓝色重点色与浅灰体系，按用户最新要求减少文字，以大字号、留白和抽象几何视觉提升整体质感；详细日程、参与说明和 FAQ 按需展开。桌面和手机共用一套导航与报名流程。工作人员安排场次和出席展位，保存草稿与明确发布为两个操作。
2. 将既有问卷导入私密联系人模块，保留来源序号及原始意向，支持按身份 / 参与方式筛选、负责人、优先级、下次跟进日期、回复和内部备注。现任 GGJ SO / RO、有意筹备新站点、讲者、展示及赞助合作分别规划；不会因标签或导入而自动获得资格、场次、展位或赞助权益。
3. 用户补充同一问卷的文字选项导出后，按来源序号核对数字版与文字版，保留原始代码、文字和规范值。缺少已核对含义的资料仍为 unknown；只有明确同意联系的联系人可进入邀请流程。历史「预计到场」不自动变成实际已回复参加。
4. 使用用户提供的邀请函视觉制作个人图片生成器。邀请称呼、日期、时段和场地可填写；默认显示暂定。生成图片、人工记录已发出、对方实际回复相互独立，生成器本身不会发送消息。
5. 用户希望先在 `artdico.host` 查看并迭代；域名注册在阿里云，香港网站桶 `artdicohost-web-hk` 已创建，PR #3 已合并且自动部署成功。后续截图显示 DNS CNAME 已启用、OSS 域名绑定生效且未开启 CDN；用户回报证书已配置、HTTPS 可显示，独立线上脚本和完整资源验收仍待执行。当前视觉升级只在本地准备，尚未部署；本地名单和内容 API 不因静态预览方案而转为云端后台。实际操作见 [OSS 部署步骤](oss-deployment.md)及 [域名与 HTTPS 操作单](domain-https.md)。继续指导控制台时仍一次一个步骤，等完成再继续。
6. Apple Wallet 和 EmailJS 账号尚未设置。先完成界面、预览、配置示例与接入说明；不发送确认信，不生成冒充有效凭证的未签名 `.pkpass`，不把预览显示为已添加 Wallet 或已送达。
