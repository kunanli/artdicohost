# 中英文公開網站

2026-11-03；基準 main `82daf5a8316e37ae9647ca8d7c84ec5020de35d8`。使用者確認保留現有簡體中文並加入英文；本站沿用 Astro、獨立 FC 與 OSS，不另建 Sites 副本。

## 使用方式與範圍

- 首次按 `navigator.languages` 順序採用第一個支援語言；zh 地區語言對應簡體中文、en 地區語言對應英文，其餘回落英文。
- 頁首「中文／EN」切換，`artdico-language` 僅記住語言；手動選擇優先於瀏覽器。瀏覽器封鎖儲存時仍可在本頁切換。無 JS 保留原中文資訊且不顯示無效切換鈕。
- 英文涵蓋導航、Hero 真文字、亮點、日程、參與指引、講者表單、驗證、草稿／恢復、狀態、固定 Q&A、既有公開隱私告知及頁尾。文件標題、描述及無障礙標籤一併處理。
- 純展示翻譯依完整來源文案及有限 UI 模板匹配；不呼叫外部翻譯服務。姓名、單位、作品名、使用者輸入、私人編號不作推測翻譯。未提供英文稿的編輯內容保留原文，英文頁尾有說明；新增或改寫文案須同步維護 `src/i18n/`。
- 語言切換不重載頁面、不重建表單，保留輸入、選項、同意與 pending 原正文。既有提交程式本來就從文件語言填入 `locale`；本輪未改資料契約。
- 一般報名仍導向原活動行網址；本站講者申請、工作人員後台、通知及名額規則保留原旅程。活動行服務本身的語言由該平台控制。後台、私人參會頁、Email 與 Wallet 不是本次翻譯範圍。

## 實作與驗證

`src/scripts/language.mjs` 僅在首頁掛載，弱引用保存每個展示節點的原文與上次顯示文字。公開更新後的新來源覆蓋舊來源；MutationObserver 在自身寫入時斷開，避免循環，不使用 innerHTML，不變更 input value、ID、連結或後端原件。中文版海報沿用原稿；英文用原有真文字 fallback，不把中文字樣圖片當英文海報。
