## 參與者只走一條路

**官網 → 活動行報名即確認 → 收到參會指南 → 本人私人頁 → 微信群／Wallet。**

1. 官網的「立即報名」指向 [這個活動行頁面](https://9525102647817.huodongxing.com/event/8884819113200)，不再同時提供第二份一般參會表單。演講提案、住宿及特別安排獨立處理，不影響普通入場資格。實際入口須等名單轉接就緒後才切換。
2. 活動行表單保留必填的姓名與Email，平台本身需要的手機照用；機構、城市等選填，不要求重填已取得資料。Email用來寄私人參會頁與行前資訊，資料用途與聯絡告知須清楚。
3. 報名成功即有活動行確認資格，不再逐人審核。完成頁建議說明：「报名成功！电子票用于现场入场，参会指南及微信群／Wallet入口将另以邮件发送，请留意报名邮箱。」首版為批次同步，不承諾即時收到本站郵件。
4. 郵件只放本人私人參會頁；群碼在頁上讀取最新有效版本，不把容易過期的靜態群碼附在郵件。Safari可添加Wallet；微信內依現有指引在Safari開啟；不使用Wallet的人仍用活動行電子票。

## 主辦方日常只有兩個動作

- **同步名單：** 從活動行匯出，本站選檔後先看新增／已存在／需核對／已取消，再確認同步。相同來源重匯略過，只處理例外，不做第二次參會審核。
- **發送參會指南：** 對已同步且取得同一份有效名額、聯絡依據完整的人，明確發送一次；已發／結果待核對者不因重匯再寄。

首版可在固定時段批次同步，活動前另做一次取消與名額對帳；不需要為此購買即時API。實際頻率由主辦方依報名量安排，完成頁和郵件不寫不存在的即時服務。

## 名額、取消與舊名單

- 先整理既有已確認者、嘉賓／工作人員及其他預留，再設定活動行可報餘量，整場只算一份共同容量。新增受邀者需同步調整餘量，不讓兩邊各自承諾名額。
- 活動行每位參加人／票的穩定ID與本站主記錄關聯；多人訂單須分人。Email／姓名只作查重線索，不自動合併不同的人。
- 已在活動行報名的人不重填；既有受邀或舊問卷人員也保留原主記錄與歷史。若要在活動行統一出票，由主辦方批次補入並回連原人，不新增第二席。
- 取消先列例外，核對是否為有效主票、是否另有其他來源後才撤回；取消一張重複票不能撤銷另一份有效名額。第一版不承諾雙向即時取消同步。
- 平台出票、資料使用依據、本人出席回覆及本站公開設定分開保留；不偽造本站隱私勾選。缺Email、來源變更或容量衝突用一個「需核對」入口處理，不暗改已確認者為候補。

## 開發接續與完成條件

1. 取得活動行匯出表頭和兩三筆完全匿名的有效／取消／多人票範例，確認穩定每人ID、狀態及時間；不使用真名單作測試。認證版已確認，不再重問是否購買方案。
2. 補活動行薄轉接器與差異預覽。現有Excel入口固定舊問卷，通用後端來源能力不等於已能直接讀活動行表格；單純建立聯絡人也不等於已同步有效名額。
3. 沿既有來源確認、主名額與通知，保留舊pending／rejected及原鍵／未知回執；不必先把本站所有公開申請改成免審。外部已出票只做技術對帳，不加第二次資格審核。
4. 驗重匯、多人訂單、同信箱不同人、取消重複票、來源變更、最後一席／候補與未知匯入／寄信；保留伺服器權限及既有128檔／40資產邊界。
5. 對接通過後，再切官網主要報名連結、收起第二個一般報名入口、更新活動行完成頁說明；真名單匯入與寄信仍由主辦方明確執行。
