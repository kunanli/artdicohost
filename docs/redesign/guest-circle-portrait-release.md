## 最終行為

嘉賓平時在原紫色圓內顯示姓名、公開組織／社群名稱及GGJ身分；滑鼠指向時在同一圓內切換本人照片。原方形浮框、公司職稱與長介紹不再出現在前台圓卡，後台原欄位與照片仍保留。姓名、組織及GGJ身分各取既有公開資料，不以職稱補GGJ身分，也不依姓名猜資料。

原生按鈕支援手機點按、Enter／Space切換、Escape還原文字。照片完成解碼才顯示；缺圖、載入中或失敗保留文字，完整身分保留在可存取名稱。照片操作提示隨中文／英文切換，公開姓名及身分原文保持；切換不改本人或圓形邊界。

原圓徑、網格及微漂浮保留，hover、focus或照片顯示時停止漂浮；減少動態、離屏與背景頁停態沿用既有規則。本輪不改出席、公開開關、名額或後台資料，不代主辦方發布業務草稿。
