## 工作人員只需三步

1. 記錄出席回覆並保存。
2. 從「需更新前台」核對關聯嘉賓與場次。
3. 預覽並明確發布。只有回覆改變時，發布操作會先保存新版本，再更新前台；不重新核准或重寄。

普通保存不發布全部草稿。發布預覽仍涵蓋當前全部已保存內容，先核對範圍；提示來源已變時重新核對，不盲目重做。操作介面不展示來源修訂或併發處理細節。
