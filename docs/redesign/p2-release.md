## 本階段範圍

| 範圍 | 已實作行為 |
| --- | --- |
| 人員入口 | 在原有人員清單找人，預設待處理並由 API 先篩選後分頁；搜尋及全部切換沿用同一入口。每人突出一個適用的下一步，阻塞只顯示一句原因與處理入口 |
| 單人工作頁 | 保留姓名、當前狀態及主要操作；原問卷、來源、歷史和進階資料按需展開。普通保存後留在同一人與位置，不加例行確認彈窗 |
| 舊意向 | 沿用原件、關聯、人工重複核對及主名額；姓名／信箱僅作核對線索，不推定同人，不因整合核准、復活或重寄 |
| 唯讀核對 | 依原角色範圍及有界來源顯示需核對項目、簡短原因與原記錄入口，跨來源核對限既有完整活動管理權限。讀取失敗、未載入或範圍不完整均顯示不可核對，不報成零問題 |
| 未知結果 | 主要操作為核對原結果，保留原操作與輸入。合併、撤回、寄信及公開發布仍各有明確動作，唯讀列表不自動修復或執行這些操作 |

操作目標只有三步：**找人 → 處理下一步 → 在同一人保存。** 詳情用來核對來源，平常不展開整頁歷史。環境與資源沿用，未規劃新增雲服務或套件依賴，執行邏輯沿用既有檔案。
