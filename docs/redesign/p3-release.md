## 本階段範圍

| 範圍 | 實作與驗收目標 |
| --- | --- |
| 私人參會頁 | 依序呈現名額狀態、活動資訊、微信群及保存參會資訊；原私人連結與即時資格核對保留。列印與邀請圖收在次要操作，換人或讀取失敗時清除前次私人資訊 |
| 入群 | 只有當前有效資格可取得群碼。缺少、過期、換圖或圖片失敗時保留可操作提示，提供重新取得與聯絡方式；顯示群碼不記為已入群 |
| 期限 | 圖片連結十分鐘有效與群碼本身最長七天分開處理；工作人員設定頁在群碼將於二十四小時內到期時提示更新，不改為二十四小時自動失效 |
| Wallet | 依裝置及瀏覽器提供可用入口與微信內開啟 Safari 的指引；Android 保留私人頁、邀請圖／列印等替代方式。不以下載成功表示已加入 Wallet |
| 資料與設定 | 沿用原名額、私人連結、群碼及簽章設定，不新增業務 journal；不因頁面讀取核准、寄信或變更正式名額 |

參與者流程為：**查看目前狀態 → 有資格時取得群碼 → 保存參會資訊。** 遺失私人連結仍由主辦方核對後私下交付，不建立公開查個資入口。

沿用現有服務與依賴。部署包仍受既有檔案、靜態資產與請求預算限制，實際大小與餘量以本階段準確來源包核對，不沿用 P2 數字作本輪通過證明。

## 部署包預算調整

候選包的官方 Node `v24.19.0` 及固定 SHA 不變，僅將 x86 BCJ／LZMA2 壓縮從 preset 6 改為 8，使用 32 MiB 字典。原 96 MiB 解碼、192 MiB 輸出、120 秒時間界限，128 檔／40 靜態資產／8 MiB 靜態上限，以及 48,000,000-byte JSON／35,999,982-byte ZIP 預算全部保留。

單一 runtime 基準：125,989,464 bytes 壓為 28,334,128 bytes，原 preset 6 為 28,636,324 bytes，節省 302,196 bytes；本地編碼約 44.67 秒、觀察峰值約 384 MiB。選用 8 保留解碼預算，亦避免 preset 9 額外約 45,792 bytes 的收益帶來更高編碼記憶體需求。這些是 runtime 壓縮基準，不是最終整包大小。

壓縮相關 22 項及準確候選包相關 5 項定向測試通過；本地既有 launcher 解碼、SHA／ELF 核對並執行官方 Node `v24.19.0` 成功，約 1.687 秒。舊 BCJ6 及 legacy 壓縮流仍相容；此本地結果不代替 CI 的完整 ZIP 離線啟動。歷史 P1／P2 產物大小及 hash 不改寫。
