## 本輪行為

「活动与内容 → 活动场次」提供就近的「发布到前台」、逐場待發布／待更新／已同步進度，以及可見的操作回饋。保存只更新草稿；發布會先顯示全部已保存內容的差異，經有發布權限的人員明確確認後更新前台。未安排草稿顯示未公開，前台仍只顯示場次主標題。

場次可在同A／B／C區、同上午／下午段內上移／下移，略過未安排草稿，不改時間、穩定ID或人員關聯。第一次手動調整以當前有效時間順序為基底；其他區的有效順序及草稿在該序列的槽位保留。前台先上午、後下午，12:00歸下午，各段內按已發布的手動順序顯示；時段篩選與深連結繼續有效。

可選欄位`content.sessionOrder`只接受`time`／`manual`。舊資料缺省仍按時間排序，讀取不補寫舊快照；首次明確調序才保存`manual`。兩個儲存層均保留舊客戶端漏傳的已存模式，明確非法值則拒絕。保存結果未知時保留原正文、先核對原結果，不另起排序或發布。

## 操作

1. 在場次頁修改並保存，核對該場的公開進度。
2. 需要調序時按同區、同半天的上移／下移，取得保存回執。
3. 按「发布到前台」，核對全部已保存變更並明確確認，再回官網重新整理。

程式部署只提供操作入口，不會替主辦方發布正式草稿或改寫既有公開講座。
