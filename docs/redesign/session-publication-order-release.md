## 本輪行為

場次頁補就近「发布到前台」、待發布／待更新／已同步標示與可見回饋。保存仍只保存草稿；發布沿既有全部已保存內容的差異預覽、權限及明確確認，未知回執先核對，不自動公開其他待確認變更。前台仍只顯示主標題，不恢復講者待確認副欄。

使用者明確要求在後台上移／下移並反映於前台日程。控制在同A／B／C區、同上午／下午段內調整，略過草稿，保留其他區及草稿在當前有效展示序列的槽位；只改展示順序，start／end及人員關聯不變。首次手動調整先將舊資料按目前有效時間順序作為基底；原陣列索引不是舊版的展示順序契約。前台仍先上午後下午，各段內依手動順序，時段篩選、定位與焦點繼續有效。
