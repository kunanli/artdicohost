# Apple Wallet 電子紀念卡申請與工作人員入場身分

2026-11-10接續使用者11月8日追加需求：Q&A說明如何取得Apple Wallet電子紀念入場卡，講者申請下方設獨立表單，收活動行報名資料、姓名、Email及微信號；卡面入場身分由工作人員設定。視覺前輪PR87獨立完成發布，不以它的檢查代替本輪申請鏈路。

## 契約差異

| 範圍 | 原行為 | 本輪行為與相容 |
| --- | --- | --- |
| 公開申請 | 一般參會外連活動行，本站general-v2講者待審 | 新wallet-v1固定四必填：活動行報名／訂單／票號文字、姓名、Email、微信；電話及機構選填。嚴格拒絕自選卡面身分、審核結果與其他隱藏欄位；舊general-v2及歷史問卷讀取與重播保留 |
| 保存／名額 | 講者不自動占席；一般報名已移至活動行 | wallet-v1一律pending_review，不占席、不觸發候補晉升。自行填入票號不是活動行已驗票證明；工作人員先核對活動行與是否已有本站主名額，相似Email不自動合併 |
| 冪等／恢復 | 有界submission token、原正文及私有OSS CAS回執 | 新walletApplication token提示只開待核對入口，不能讓普通報名通過speaker_only。遺失ACK用同key／原正文核對，已保存重播可跨申請關閉；未同意、未保存或讀取失敗不顯示成功 |
| 本機草稿 | general-v2獨立事件／表單scope | wallet-v1另有scope，與講者草稿互不覆蓋；成功後清除。未決正文保持不可變，token及同意勾選不寫編輯草稿；重整不自動POST，明確按鈕才核對原申請 |
| 內部身分 | Wallet只顯示名額已確認 | 私有review新增可省略walletIdentity，固定八選一；未選仍為待確認。舊客戶端漏傳保留已保存值，明確空值可清除；同review revision CAS及審計保留。標籤不授予後台帳號權限或名額 |
| 主名額／別名 | 已有人工關聯、共同名額與私人頁 | 後台GET提供受控walletIdentityTargetId；別名不能保存無效的卡面身分，介面連回主名額設定。Wallet只使用目前主名額的卡面身分，不按姓名或Email猜配對 |
| Wallet | 既有簽章、本人名稱、官方活動資料及入場QR | 保留既有簽章／驗票入口。工作人員選定身分寫入卡面header；紀念卡申請未確認名額或未設定身分不能取得新卡。簽章前後再核對身分及資格，避免返回過時標籤；舊卡缺省維持原「已確認」顯示 |
| Q&A／公開資料 | 已發布快照可含舊題目與回覆 | 必要wallet-card說明及固定本頁申請錨點由前台只讀投影補齊，不覆寫既有業務草稿／凍結快照。報名編號、Email、微信及內部review不進匿名公開內容 |

身分選項：一般來賓、嘉賓、講者、參展者、GGJ組織者、學生、工作人員、志願者。這是工作人員明確選定的卡面文字；參會資格與帳號權限仍依既有系統核對。普通參會入口維持活動行，沒有活動行登入／即時API同步或對活動行回寫。

## 工作人員操作

1. 從「人員與報名」查看紀念卡申請；報名詳情顯示活動行編號、Email與微信。核對活動行名單及既有本站人員；已有主名額時明確關聯同一人，避免新增第二份名額。
2. 在報名詳情選「紀念卡入場身分」，普通保存留在本條。已關聯別名會提供「到主名額設定紀念卡身分」，不可把不生效的別名標籤誤稱保存到卡面。
3. 核對實際主名額狀態；需要時依既有名額審核流程確認。卡面身分本身不核准參會。
4. 使用既有確認函預覽與明確寄送，申請人從本人私人頁取得Wallet。申請、保存標籤、匯入或部署都不等於已實寄／已加入iPhone。

## 發布、回退與保留

沿既有FC私有OSS、公開OSS、確認信與Wallet簽章配置，沒有新環境變數、憑據、服務、DNS或依賴。公開表單及Q&A沿新統一字體角色；所有照片／Logo與業務資料不因本輪部署改寫。新共用validator併入現有registration-domain chunk，使後台圖閉包維持42資產及原137檔／bytes預算。

新wallet-v1原始記錄及review.walletIdentity必須保留於現有加密備份／刪除範圍（registrations與registration-reviews journal及不可變record），參照[維護流程](../maintenance-backup.md)。刪除申請仍走工作人員受控維護，不能宣稱登記即已擦除。舊程式不認得新intake／review欄位，因此回退須部署保留這兩項讀取與冪等回執的相容修正版；不可直接回到PR87後清除新記錄或未知操作。沒有以本輪程式代為提交真人申請、合併人員、核准名額、實寄或調整群碼。
