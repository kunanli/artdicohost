# 嘉宾与组织图片编辑

当前开发分支 `feat/staff-image-editor`；发布完成前不能把本机编辑能力当作线上已可用。用户反馈的 `CONTENT_NOT_READY`／「云端内容后台尚未开放」对应部署的关闭边界；上一轮准确 main `b51dff2` 已于 10:37:45（UTC+08）恢复启用，10:38:32 完成 23 个 HTTPS 对象回读。

## 操作

在嘉宾或组织编辑表选择图片，或点击「编辑现有照片／图片」。现有图片透过工作人员鉴权读取并核对格式、大小与内容摘要，不生成公开下载地址。

选择裁切比例后可拖动位置、调缩放，亦可用方向键／方向按钮。嘉宾默认方形；组织默认原图比例。取色工具点击要去除的背景色，再执行单色去背并调整容差；仅移除与图片边缘相连的近似颜色，封闭内部细节会保留。复杂区域可用擦除／还原画笔，支持撤销及还原原图背景。棋盘仅表示透明，不会画进输出图片。

「应用图片并上传」只上传编辑后的私有图片；之后仍需应用嘉宾／组织资料、保存草稿，再另行发布。取消图片编辑不会上传或移除原照片。上载失败时原引用与已填写内容保留；如已生成待上传结果，点击「重试上传」会使用同一份像素内容，或「取消本次图片」保留原照片继续编辑。未解决待上传结果前不能套用整份资料，避免把新预览误认为已关联。

服务暂不可用时显示更新提示；不会自动重送。会话失效或退出会清除编辑画布、待上传内容及表单。已点击上传后取消等待，不把晚到回执关联到别的资料；图片仍须通过原有保存／发布授权。预览读取失败保留原引用，服务恢复后可重新编辑或选择文件。

## 图片与处理边界

原图限静态 JPEG／PNG／WebP，最多 12 MiB／四千万像素，先读安全头再解码；自动校正 EXIF 方向。编辑工作图最长 1200px，输出最长 800px；只在当前浏览器处理，不传原图到其他图片服务。实际有透明度时保留 PNG，必要时有界缩小至最多 512 KiB；不透明图继续使用 JPEG 压缩，输出均重新编码移除元数据。旧调用默认 JPEG 行为保留，学生作品封面处理不改变。

组织实际图片取消额外灰底、10px 内距与固定高度，按自然比例展示，CSS 不截掉 Logo。嘉宾保留圆形展示与 cover，去除额外灰色框边。图片本身像素内的空白可用裁切／缩放／去背调整。

## 验证与接续

纯算法验证裁切几何、背景边缘连通、内部细节、软画笔与透明还原边界；格式回归验证 PNG RGBA／tRNS、元数据移除与本机／云端存储重建。`tests/browser/profile-transparency-smoke.mjs` 用真实拦截 Chromium 验证透明 0／128／255、旧白底 JPEG、不透明 JPEG、方向及大噪声 PNG 缩小，不接真实 API。

`tests/browser/staff-image-editor-smoke.mjs` 用完全合成图与拦截 API 验证真实像素、去背／画笔／撤销、手机拖动、明确应用、取消、503 原 payload 重试、401 清理及晚到回应。它不使用用户截图里的组织或真实照片作夹具。完整本机／准确 PR／main 检查与实际上线证据继续写入接续台账。
