# 后台快捷导航与独立页面

当前提供六个工作人员工作区：今日待办、人员与邀约、志愿者与分工、报名与审核、活动与内容、设置与通知。当前页以蓝色及aria-current标记；个人工作页标记人员与邀约父入口。导航随登录显示，退出／会话失效隐藏，真正访问权限仍由服务端执行。

内容有九个独立页面：概况、活动基本资料、现场配置总览、嘉宾与讲者、参与组织、游戏与作品、活动场次、十五个展位、预览与发布。路径为 `/admin/content/{overview,event,arrangements,guests,organizations,showcases,sessions,booths,publish}/`。每页仅显示所属区块，可以直接打开、刷新与返回，不再用一张长表滚动定位。

设置独立路径 `/admin/settings/{delivery,group,invitations,accounts}/`，分别是报名确认与票券、微信群入口、工作人员邀请、用户管理。旧 `/admin/`、`/admin/settings/` 及原锚点／稳定实体ID深链保留兼容，转到正确所属页。账号管理仍仅管理员可访问。

当前区块底部提供主要保存，实体编辑器右下直接保存。未保存离页可选保存并前往、继续编辑或明确放弃；未知回执先核对原请求。导航不会自动保存、公开或发信，云端保存后仍由有发布权限者在预览与发布明确公开。

1100px起左栏常驻，较小屏幕使用快捷导航收合菜单；Escape关闭并交回焦点，短屏菜单内部滚动、表格局部横向滚动。当前页标记按实际独立路由，旧同页锚点仍支持标题焦点定位。
