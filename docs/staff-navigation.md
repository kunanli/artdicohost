# 后台快捷导航

四个工作人员工作区统一提供左侧导航：今日待办、人员与邀约、报名与审核、活动与内容。当前页面以蓝色标记；访问权限仍由原页面及服务端校验。导航随登录工作区显示，退出或会话失效后隐藏。

活动与内容页另有区块直达：概况、活动基本资料、现场配置总览、嘉宾与讲者、参与组织、学生作品、活动场次、十五个展位。点击后定位标题并移交键盘焦点，当前区块随滚动更新。页面内跳转不会应用表单、保存草稿或发布；切换其他工作区继续使用原有未保存离页提醒。既有人员／展位深链继续交原编辑器处理。

1100px 起采用左侧常驻布局；较小屏幕使用顶部「快捷导航」收合选单，滚动时仍可打开。点选区块后收起，Escape 可关闭并将焦点交回开关。短屏幕菜单内部滚动，表格继续在原容器中横向滚动。标题定位即时完成，不依赖动画。

`tests/browser/admin-navigation-smoke.mjs` 通过拦截全部网络的合成 Chromium 验证；正式发布依照既有 PR、准确 main CI、FC 私有 OSS 隔离验收及公开文件哈希回读，不以本机构建代替上线证据。
