## 本机草稿边界

- 自动暂存本机不等于云端保存、审核通过或发布，界面用紧邻输入的简短状态区分。
- 公开填写仅保存白名单字段；恢复不自动勾选隐私同意。不保存会话、密码、API 密钥、提交 token 或私人确认凭证。
- 首次提交前持久保存原始 JSON 和同一 idempotency key。结果未知时保留冻结原件，刷新后只能明确核对同一申请；不自动 POST、换键或改写原隐私版本。先前已未知的操作不能因后续 422 就忘记原键。
- 工作人员草稿绑定当前账号、活动、页面及对象，只在鉴权后恢复。原云端修订不同须显示冲突，不能覆盖其他人的修改；登出或账号切换清理可见输入与异步回应。
- 图片文件、上传结果与表单应用／云端保存／公开发布须保持不同状态。未确认保存回执不清除唯一恢复副本。
- 浏览器缓存损坏、配额不足、隐私模式及多页签不能伪称已暂存，未知写入仍保留原操作身份。
