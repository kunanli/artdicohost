# 邀请函模板

`template-blank.png` 基于用户提供的 `邀请函-模板.png`，通过内建 Image Generation 编辑生成。仅请求移除称呼、日期、时间、地点的示例值，以便浏览器绘制变量；原文件未被改动。生成模型会重建像素，模板保留原版视觉构图，并非像素级无损去字。

该文件只含用户提供的公开活动设计元素，不含真实报名记录或个性化称呼。公开静态文件不能保存生成给真实联系人的邀请函；生成结果只在浏览器内绘制并由工作人员下载。

源图示例日期、时间和地点尚未确认，生成器默认添加「暂定 · 信息待确认」。只有工作人员明确确认完整活动信息后，才允许去除暂定标记。生成图片不会发送邀请，也不会自动将联系人标记为已邀约。

编辑提示词：保持原构图、标志、标题、赞助文案、口号、底部光环球体不变，仅清除 TuTuHu、2026/12/05、10:00-18:00、深圳前海5号楼3F 的文字并恢复底色，保留「诚邀」「时间」「地点」与分隔线。
